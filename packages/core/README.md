# @fluxory/core

Shared internals for the [fluxory](https://github.com/ashishgautam02/fluxory-npm) observability suite.

Provides trace ID generation, context propagation, span transport, and the custom tracker API used by `@fluxory/node` and `@fluxory/client`.

You don't need to install this directly — it's included as a dependency of the SDK packages.
